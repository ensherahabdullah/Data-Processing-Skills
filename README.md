# Data Processing Skills

This repository documents hands-on Python practice in Pandas DataFrame operations and fundamental natural language processing (NLP) techniques.

## Practice Notebooks

### 1. Pandas DataFrame Operations — Lab9

- Creating and combining DataFrames
- Applying different types of joins
- Handling missing values
- Grouping and aggregating data
- Visualizing average salaries

### 2. Text Preprocessing & NLP

- Text cleaning and normalization
- Word and sentence tokenization
- Stopword removal
- Stemming and lemmatization
- Word frequency analysis
- Word cloud visualization

## Tools & Libraries

- Python
- Pandas
- Matplotlib
- NLTK
- WordCloud

## Dataset

The NLP practice notebook uses `sentimentdataset.csv`.

**Source:** [Sentiment Dataset — Kaggle](https://www.kaggle.com/datasets/rishijmanna/sentimentdataset)

The Pandas DataFrame notebook uses sample data created directly in Python.

## How to Run

1. Open the notebooks in Google Colab or Jupyter Notebook.
2. Download `sentimentdataset.csv` from the Kaggle link above for the NLP notebook.
3. Upload the dataset to the Colab session if using Google Colab.
4. Run the notebook cells in order.

## Notes

These notebooks demonstrate practical applications of Python libraries and data-related techniques. They represent hands-on exercises rather than standalone end-to-end projects.
